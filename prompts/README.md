# Prompt Library

This directory contains all enterprise prompts used during the development of PhuQuocHub.

These prompts are **development tools**.

They are NOT part of the software architecture.

They do NOT override

- ADR
- Architecture
- Database
- API
- OpenAPI
- RBAC

The Single Source of Truth (SSOT) remains the documentation under docs/.

Whenever a prompt conflicts with the SSOT,
the SSOT always wins.
