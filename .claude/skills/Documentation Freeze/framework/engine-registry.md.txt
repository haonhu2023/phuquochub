# Engine Registry

---

# 1. Purpose

The Engine Registry

is the authoritative registry

of every validation engine

participating

in

the Documentation Governance Framework.

The registry

provides

centralized discovery,

registration,

configuration,

dependency resolution,

capability management,

and lifecycle control

for

all validation engines.

The Validation Orchestrator

must never

hard-code

validation engines.

Instead,

all engines

shall be discovered

through

the Engine Registry.

---

# 2. Mission

Guarantee

Complete Engine Discovery

Engine Identity Integrity

Capability Discovery

Execution Planning

Dependency Awareness

Lifecycle Governance

Version Compatibility

Framework Extensibility

# 3. Why Engine Registry Exists

Without

a centralized registry,

the Orchestrator

must know

every engine

explicitly.

Example

Metadata Validation

↓

Dependency Validation

↓

Cross Validation

↓

SSOT Validation

↓

Orphan Validation

↓

Freeze Decision

This approach

does not scale.

Every new engine

requires

changes

inside

the Orchestrator.

The Engine Registry

removes

this coupling.

The Engine Registry

governs
