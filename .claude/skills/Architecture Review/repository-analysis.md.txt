# Purpose

This document defines

the official repository analysis policy

for the PhuQuocHub platform.

Before making any architectural decision,

Claude Code must understand

the current repository.

Repository Analysis

is always performed

before Architecture Review.

---

# Mission

Understand

the repository,

its structure,

its current implementation,

its completed work,

its missing work,

its technical debt,

and its architectural status.

Repository Analysis

must never

modify implementation.

---
