# Purpose

This document defines

the official naming convention review policy

for the PhuQuocHub platform.

Naming conventions

must remain

consistent,

predictable,

searchable,

and documentation-driven.

Every name

must communicate

its purpose

without ambiguity.

---

# Mission

Maintain naming consistency.

Prevent naming drift.

Improve readability.

Improve discoverability.

Guarantee long-term maintainability.

---

# Core Principles

Names must be

Clear

Consistent

Descriptive

Stable

Predictable

Documentation-compliant

Never abbreviate

unless officially documented.

# Repository Naming

Repository names

must use

kebab-case

Examples

phuquochub

admin-portal

search-engine

Forbidden

PhuQuocHub

phuQuocHub

phu_quoc_hub
