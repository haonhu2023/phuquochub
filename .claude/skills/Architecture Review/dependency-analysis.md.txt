# Purpose

This document defines

the official dependency analysis policy

for the PhuQuocHub platform.

Every dependency

must be intentional,

documented,

traceable,

and compliant

with the architecture.

Dependency analysis exists

to prevent

architecture erosion,

tight coupling,

hidden dependencies,

and circular references.

---

# Mission

Maintain a clean dependency graph.

Prevent architectural degradation.

Guarantee module isolation.

Protect long-term maintainability.

Detect dependency drift early.

---

# Core Principles

Every dependency

must satisfy

Necessity

Documentation

Architecture

Ownership

Traceability

Testability

Reviewability

No dependency

may exist

without a documented reason.

# Layer Dependency Rules

Controllers

↓

Services

↓

Repositories

↓

Database

must never

import repositories.

Services

must never

query SQL directly.

Repositories

must never

Entities

must never

depend on infrastructure.
