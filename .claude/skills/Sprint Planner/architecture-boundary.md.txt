# Purpose

This document defines the architectural boundaries
that Claude Code must never violate.

Architecture is frozen after Documentation Freeze.

Implementation follows architecture.

Architecture never follows implementation.

---

# Core Principle

Architecture is the Single Source of Truth.

Implementation must adapt to architecture.

Architecture must never adapt to implementation.
