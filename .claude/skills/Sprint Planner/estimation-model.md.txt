# Purpose

This document defines the mandatory estimation model
used throughout the PhuQuocHub project.

Every estimation must be based on measurable evidence.

Never estimate using intuition.

Never estimate using optimistic assumptions.

All estimates must be reproducible.

---

# Core Principle

Planning quality depends on estimation quality.

Good estimation reduces

- schedule risk

- architecture drift

- sprint failure

- merge conflicts

- production defects

Poor estimation causes

- unrealistic deadlines

- oversized batches

- hidden technical debt

# Success Criteria

The estimation model succeeds when

Sprint duration is predictable,

Batch size remains reviewable,

Risk is visible before implementation,

and Claude Code can plan work
without relying on subjective judgement.
