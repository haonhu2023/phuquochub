# Purpose

This document defines the review policy
for the PhuQuocHub project.

All reviews must be

Objective

Repeatable

Evidence-based

Read-only

Traceable

No review
may rely on assumptions.

---

# Core Principle

Review never modifies implementation.

Review only evaluates implementation.

Implementation and review
must remain independent.

# Review Rules

Every review

must be

Read-only

Never modify files.

Never generate code.

Never redesign architecture.

Never invent missing documentation.

Never assume implementation.

---

# Evidence Rules

Every conclusion

must cite evidence.

Evidence may include

Repository files

Documentation

ADR

Decision Register

OpenAPI

Migration

Configuration

Tests

CI

If evidence is missing

Output

NOT FOUND

Never guess.

---

# Success Criteria

The Review Policy succeeds when

every review

is repeatable,

objective,

evidence-based,

traceable,

and independent
from implementation.

No review
may influence architecture.

No review
may modify implementation.

Review exists only
to determine compliance
with the frozen documentation.
