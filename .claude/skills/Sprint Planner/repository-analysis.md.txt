# Purpose

This document defines the mandatory repository analysis
performed before any planning or code generation.

Repository Analysis is the first step
of every implementation cycle.

Claude Code must understand the current repository
before making any implementation decision.

No code shall be generated
without completing Repository Analysis.

---

# Core Principle

The repository is the current implementation truth.

Documentation is the architectural truth.

Planning must compare both.

Never overwrite existing implementation.

Never duplicate implementation.

Never regenerate completed work.

---
