Before publishing a report

Every finding has evidence

Every decision is justified

No undocumented assumptions

No architecture changes proposed

No code generated during review

# Success Criteria

The Output Template succeeds when

every report produced by Claude Code

shares the same structure,

the same terminology,

the same evidence model,

and the same decision framework,

making reports comparable
across all Sprints,
all Batches,
and the entire lifecycle
of the PhuQuocHub project.
