# Primary Keys

Every table

must have

one

Primary Key

UUID

preferred.

Auto Increment IDs

are prohibited

unless

performance justification

is documented.

---

# Foreign Keys

Every relationship

must enforce

Referential Integrity.

Foreign Keys

must never

be omitted

without

architectural approval.

---

# Relationship Standards

Supported

One-to-One

One-to-Many

Many-to-Many

Self Reference

Polymorphic

only when approved.

---

# Junction Tables

Many-to-Many

must use

explicit junction tables.

Example

hotel_tag

place_category

tour_destination

---

# Soft Delete

Soft Delete

is mandatory

for

Business Data.

Implementation

deleted_at

TIMESTAMP NULL

Never use

is_deleted

unless justified.

# Versioning

must support
