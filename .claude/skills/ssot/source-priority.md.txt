# Purpose

This document defines

the official Source Priority

for the PhuQuocHub platform.

Source Priority

determines

which documentation

must be consulted first,

which documentation

takes precedence,

and

how Claude Code

must resolve

multiple available sources

during planning,

implementation,

review,

validation,

and production release.

This policy

guarantees

consistent,

deterministic,

and evidence-based

decision making.

---

# Mission

Ensure

every decision

is made

using

the highest priority

available source.

Prevent

conflicting interpretations.

Prevent

AI hallucinations.

Prevent

implementation-driven decisions.

---

# Fundamental Principle

Claude Code

must always

prefer

higher-priority sources

over

lower-priority sources.

Lower-priority sources

may only

supplement

higher-priority sources.

They may never

override

them.

# Multi-Source Resolution

If

multiple sources

exist,

Claude Code

must

load

them

from highest

to lowest.

Stop

when

sufficient evidence

has been collected.

---

# Conflict Resolution

If

two sources

conflict,

higher priority

wins.

Lower priority

must be reported

as

documentation drift

or

implementation drift.

Claude Code

must never

merge

conflicting information.

---

# Missing Source

If

a required source

does not exist,

Claude Code

must continue

using

the next

available

higher-level

approved source.

If

no authoritative source

exists,

return

NOT FOUND.

---

# Repository Rule

Repository

may confirm

documentation.

Repository

may not

replace

documentation.

Repository

may reveal

drift.

Repository

may not

change

authority.

---

# Generated Code Rule

Generated files

must never

be reviewed

as

architectural truth.

Generated files

inherit

their authority

from

the documents

that produced them.

---

# Validation Rules

Before

any answer,

Claude Code

must verify

Highest priority source loaded

Lower priority sources checked

No unresolved conflicts

Evidence collected

Authority respected

The Source Priority policy succeeds when

every architectural review,

documentation review,

Sprint plan,

Batch plan,

and production decision

is based on

the highest available

authoritative source,

with all lower-priority sources

used only

to support,

or identify drift,

traceable,

and deterministic

decision making

across the entire

PhuQuocHub platform.
