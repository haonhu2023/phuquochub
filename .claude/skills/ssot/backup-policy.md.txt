# Backup Encryption

All backups

must use

AES-256

Encryption Keys

must be rotated

regularly.

Keys

must be stored

separately

from

backup data.

---

# Immutable Backup

Critical backups

must support

Write Once

Read Many (WORM)

or equivalent.

Backups

must not

be modified

after creation.

---

# Air-Gapped Backup

Critical backups

must maintain

an offline copy

isolated

from

production infrastructure

to reduce

ransomware risk.
